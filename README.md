# INK
## What is it?
its a web app where you can put on some effects on an image
these effects are based on how often i use them in my graphics design!

Made with `HTML` `CSS` `JavaScript`

### Features
* Halftone effect
* Add noise
* Dither effect
* Pixelate images
* Analog effects
* Blend between the original image and the effect
* Dark and light mode

 ### HOW TO USE!

1. Open [INK][https://createvision96.github.io/INK/]
2. Drop an image into the image area or click it to select an image
3. Select an effect from the left panel
4. Adjust the settings on the right
5. Use **Blend** to mix the original image with the effect
6. Hold **Before** to view the original image
7. Click **Export** to save the result
